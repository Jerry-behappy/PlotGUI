# PlotGUI Web

将 PlotGUI 的 Python 数值处理迁移到浏览器，支持 TXT、CSV、DAT。双击本目录的 `index.html`，使用 Edge 或 Chrome 打开；无需安装 Python、MATLAB 或 npm 依赖。整个 `web` 目录需保持完整，也可用 `python web/package_web.py` 生成独立 HTML。

## 文件与绘图

- 选择文件夹、选择多个文件，或将文件/文件夹拖入页面。拖入文件夹会递归读取子目录。
- 单击文件复选框切换选择；不需要 Ctrl。双击文件行或点击“预览”查看前 200 行原始数据。
- 按原版选择 X/Y 列，列号从 1 开始。首次导入只有两列的文件时，默认 Y 列由 3 调整为 2。
- 导入不超过 12 个条目时选中全部新文件；大批量导入默认保留首条选择，避免无意绘制大量曲线。可随时全选。
- 同一路径重新导入会更新该文件。普通文件选择器提供快照；“连接实时文件夹”使用支持浏览器的 File System Access API，以只读方式每 3 秒检查变化。连接不跨页面刷新保存。

## 数值行为

`plot_core.js` 对应 `python/plot_core.py`，处理顺序为缩放 → 重叠区间内线性插值扣除校准 → Y 补偿 → MATLAB `movmean` 风格的移动平均。偶数窗口、缩短边缘窗口、校准 X 去重规则与原版一致。两曲线相减只取重叠 X 范围，B 插值到 A；沿用原版的派生曲线二次 smooth 行为。额外提供 A/2+B/2 运算。

原始数组保存在页面内存中。隐藏 −210 点只是显示选项，不改变数值处理；不默认推定仪器特殊值含义。校准参考相减不能直接解释为器件本征损耗。

## 图窗与复制

- 默认微软雅黑、实线、3 px 线宽；轴标签/刻度/图例字号为 24 px，图下分析 17 px。每条曲线标出最大点。
- X/Y 支持 linear/log、手动范围、自动范围；“1310 预设”快速设置 1270–1350 nm 与 −55–−5 dB。
- 平移、缩放与 Plotly Autoscale 只改变画面，不修改范围控件。点击“应用设置”恢复设定范围。
- `yline` 使用当前 X/Y 窗口内的处理后数据，缩放后即时更新；标签仅显示数值。
- PNG 以 3000×3000 图片写入剪贴板；SVG 复制为源码文本；“复制数据”复制所选曲线在当前 X/Y 窗口内的 `X,Y` CSV 文本。
- 浏览器拒绝剪贴板写入时弹出手动复制窗口。SVG/CSV 可选中文本按 Ctrl+C；PNG 可右键复制图片。
- 标题、轴标签、图例与分析文字可拖动；图例可重命名、设位置与列数。多列图例通过水平图例自动换行排列；“自动”位置使用右上角。
- 图形参数与图例名称保存在当前浏览器本地存储；文件数据不保存、不上传。

## 验证

```shell
node --test web/tests/core.test.cjs
```

测试包括原版 Python 的数值对照，需现有 Python/NumPy 环境。网页运行不需要 Python。浏览器受安全机制限制，无法直接执行桌面版的任意目录轮询或写入指定硬盘路径；实时文件夹功能仅在用户授权后可用。

第三方绘图运行时为 Plotly.js 2.35.2，随页面离线提供，许可证见 `vendor/`。
